Hacer una matriz que almacene la cantidad de computadoras vendidas de tres vendedores en cuatro zonas.

mostremos:
    - La zona en la que se vendio mas computadoras
    - El vendedor con menos ventas
    - Cantidad vendida por todos los vendedores en todas las zona

Que necesito hacer:
    - una forma para sumar todas las ventas en cada zono y ver cual es la que vendio mas, probablemente pueda hacerlo con algunos for y utilizando ifs para detectar el mayor
    - Tambien tener una forma de ver cual es el que vendio menos de todos los vendedores
    - Finalmente sumar todas las ventas en general lo cual lo puedo hacer con un simple sum a la lista, almenos esa es la idea inicial, pero probablemente se complique mas que solo eso

Structura de la matriz de ventas
    ventas = [
        [Zona 1, Zona 2, Zona 3, Zona 4] Vendedor 1
        [Zona 1, Zona 2, Zona 3, Zona 4] Vendedor 2
        [Zona 1, Zona 2, Zona 3, Zona 4] Vendedor 3
    ]

Dividiremos el ejercicio en incisos

    a. Suma de ventas por zona

    b. Sumar ventas por vendedor

    c. Suma de todas las ventas

    d. Mostrar todos los anteriores puntos de manera estetica
